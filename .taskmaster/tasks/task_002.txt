# Details:
This task involves implementing the Repository Pattern to abstract database access:

1. Create a base repository interface with common CRUD operations:
   ```python
   class BaseRepository(ABC):
       @abstractmethod
       async def get_by_id(self, id: Any) -> Optional[Any]:
           pass
           
       @abstractmethod
       async def get_all(self) -> List[Any]:
           pass
           
       @abstractmethod
       async def create(self, entity: Any) -> Any:
           pass
           
       @abstractmethod
       async def update(self, entity: Any) -> Any:
           pass
           
       @abstractmethod
       async def delete(self, id: Any) -> bool:
           pass
   ```

2. Implement entity-specific repositories for each domain entity (e.g., User, Product, Order):
   ```python
   class UserRepository(BaseRepository):
       def __init__(self, db_session: Session):
           self.db_session = db_session
           
       async def get_by_id(self, id: int) -> Optional[User]:
           return await self.db_session.query(User).filter(User.id == id).first()
           
       # Implement other methods...
   ```

3. Create a transaction management utility:
   ```python
   class UnitOfWork:
       def __init__(self, session_factory):
           self.session_factory = session_factory
           
       async def __aenter__(self):
           self.session = self.session_factory()
           return self
           
       async def __aexit__(self, exc_type, exc_val, exc_tb):
           if exc_type is not None:
               await self.rollback()
           else:
               await self.commit()
           await self.session.close()
           
       async def commit(self):
           await self.session.commit()
           
       async def rollback(self):
           await self.session.rollback()
   ```

4. Identify and catalog all 157 direct database queries in controllers and other components.

5. Systematically replace each direct query with calls to appropriate repository methods.

6. Update service classes to use repositories instead of direct database access:
   ```python
   class UserService:
       def __init__(self, user_repository: UserRepository):
           self.user_repository = user_repository
           
       async def get_user(self, user_id: int) -> Optional[User]:
           return await self.user_repository.get_by_id(user_id)
   ```

7. Implement dependency injection for repositories in service classes and controllers.

8. Ensure all database transactions are managed through the UnitOfWork class.

9. Update tests to use repository mocks instead of database mocks.
