# Task ID: 4
# Title: JS Module Scaffolding
# Status: in-progress
# Dependencies: 3
# Priority: high
# Description: Create four ES modules: api.js (API routes), state.js (in-memory state), render.js (render functions), main.js (bootstrap and events) to establish the core JavaScript architecture for the application.
# Details:
1. Create app/static/api.js module:
   - Export functions for all API interactions (GET/POST/PATCH/DELETE)
   - Include error handling and response parsing
   - Functions: fetchTasks(), createTask(), updateTask(), deleteTask(), fetchInfo()
   - Use fetch API with proper headers and error boundaries

2. Create app/static/state.js module:
   - Implement in-memory state management for tasks, filters, and UI state
   - Export state object with getters/setters
   - Include state validation and change notification system
   - State properties: tasks, currentTag, filters, loading states

3. Create app/static/render.js module:
   - Export functions for rendering UI components
   - Functions: renderTaskCard(), renderKanban(), renderFilters(), updateCounters()
   - Include DOM manipulation utilities and template functions
   - Handle dynamic content generation from state data

4. Create app/static/main.js module:
   - Bootstrap application initialization
   - Set up event listeners for user interactions
   - Coordinate between api, state, and render modules
   - Include DOMContentLoaded handler and error boundaries

# Test Strategy:
1. Verify all four JavaScript files are created in app/static/ directory
2. Confirm each module exports expected functions using ES6 export syntax
3. Test api.js functions can make HTTP requests to backend endpoints
4. Validate state.js maintains consistent data and triggers updates
5. Check render.js functions generate correct DOM elements
6. Test main.js initializes application and handles events properly
7. Verify modules can import and use each other's functionality
8. Test error handling in each module responds appropriately to failures
